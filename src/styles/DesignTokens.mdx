# Design tokens

Tokens for the custom, non-PrimeVue pieces of croM (the interval timeline, key badges,
active/inactive states). Defined in `src/styles/_variables.scss` — that file is the
single source of truth; update the swatches below if you change a value there.

Everything else (buttons, inputs, tables, dialogs) uses PrimeVue's own Aura theme.
